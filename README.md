# Hackathonaddovedi

A simple, responsive calculator built with plain HTML, CSS, and JavaScript.

## Run it

Open `index.html` in any modern web browser. No installation or build step is
required.

Use the on-screen buttons or your keyboard. Keyboard shortcuts include the
number keys, `+`, `-`, `*`, `/`, `.`, `Enter` (calculate), `Backspace` (delete),
and `Escape` (clear).
